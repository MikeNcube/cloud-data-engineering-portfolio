# Cloud Data Engineering Portfolio

This repository showcases end-to-end Cloud Data Engineering skills, aligned with the **Desperately Hunted Skills for 2026+**.

## Skills Demonstrated

- **Cloud Platform & IaC**: Terraform, AWS S3, RDS, DynamoDB
- **Real-Time Data & Data Quality**: Kinesis, Great Expectations, CloudWatch monitoring
- **Orchestration & Governance**: Airflow DAGs, Neo4j / Graph Databases, Data Contracts

## Project Structure

cloud-data-engineering-portfolio/
│
├─ main.py # Example streaming pipeline
├─ pipeline_dag.py # Airflow DAG
├─ main.tf # Terraform IaC example
├─ great_expectations.yml # Data quality config
├─ requirements.txt # Python dependencies
└─ README.md
